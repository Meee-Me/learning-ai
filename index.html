Connect a website

Max edits the website's files on GitHub. Your host (Vercel, Netlify and others) then rebuilds the site by itself, and Max tells you when the change is live.

One-time setup. GitHub only shows its Authorize screen for apps it knows, so Max has to be registered with GitHub once. After this, connecting is just a tap.

  1. Open GitHub → New OAuth App.
  2. Name: Max Tutor. Put this address in both Homepage URL and Authorization callback URL:
  3. Tick Enable Device Flow, then tap Register application.
  4. Copy the Client ID it shows (it starts with Ov23) and paste it here. Don't make a client secret.

Use access tokens instead

GitHub

How do I get a token?
  1. On github.com open Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Tap Generate new token. Under Repository access pick Only select repositories and choose this one repository.
  3. Under Permissions → Repository, set Contents to Read and write. To let Max see when the site is live, also set Commit statuses and Deployments to Read-only.
  4. Generate it, copy it, and paste it here.

Vercel optional

How do I get a Vercel token?
  1. On vercel.com tap your picture → Account Settings → Tokens.
  2. Tap Create, name it "Max", choose the team your site is in, and pick an expiry date.
  3. Copy the token and paste it here.

Netlify optional

How do I get a Netlify token?
  1. On app.netlify.com tap your picture → User settings → Applications.
  2. Under Personal access tokens tap New access token, name it "Max".
  3. Copy the token and paste it here.

Vercel and Netlify tokens are only needed if you want Max to read build error logs. He only reads from them.

Your GitHub access stays in this browser. When you use Connect GitHub it passes through Max's server once, on its way from GitHub to you, and is not kept there. It is never sent to Max's AI. The files Max opens are sent to his AI service, so don't connect a repository with secrets in it.
